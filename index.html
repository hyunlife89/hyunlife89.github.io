02 — 선생님

우리 반 문제로
게임하기

선생님이 구글 시트에 문제를 적으면, 그 반 학생들 게임에 그 문제가 나와요.

  • 문제와 학생 기록은 선생님 구글 드라이브에만 저장돼요. 오락실 서버에는 남지 않아요.
  • 과학이 아니어도 돼요. 객관식(보기 2~4개)과 OX 문제면 어느 과목이든 들어가요.
  • 시트를 고치면 학생이 게임을 다시 열 때 바로 바뀌어요.
  • 연결하면 이 화면의 QR·링크에 우리 반 코드가 붙어요. 학생은 한 번만 들어오면 기기가 기억해요.

우리 반 문제가 들어가는 게임

  • 엑스탱크 스쿨 — 단원 고르기에 '우리 반' 묶음이 생겨요 (선생님 방·혼자 연습)
  • 과학 포트리스 — 설정의 '우리 반 문제'에 자동으로 더해져요 ('우리 반 문제만 내기' 가능)
  • 밤의 과학실 탈출 — 포트리스와 같아요
  • 등대섬 수비대 — 준비 중 · 카누·찌릿·룰렛 — 교과서 이야기에 맞춘 게임이라 기본 문제만 써요

세 단계면 끝나요. 구글에 로그인된 컴퓨터에서 해 주세요.

3여기에 붙여 넣기

    학생 링크

    학생 점수까지 시트에 남기고 싶다면 (선택 · 10분)

    누가 어떤 문제를 맞혔는지 시트에 쌓여요. 1번 시트에서 이어서 해요.

    1. 시트 위쪽 메뉴 확장 프로그램 → Apps Script
    2. 열린 창의 글을 모두 지우고 한 것을 붙여 넣고 💾 저장
    3. 오른쪽 위 파란 배포 → 새 배포 → 톱니바퀴 ⚙ → 웹 앱
    4. 맨 아래 액세스 권한만 모든 사용자로 바꾸고 배포
    5. "확인되지 않은 앱" 창이 뜨면 고급 → 맨 아래 …(으)로 이동 → 허용
      선생님이 직접 만든 스크립트라 구글이 한 번 더 묻는 거예요.
    6. 나온 웹 앱 URL(…/exec)을 복사해서 위 3번 칸에 붙여 넣기
    QR 한 번카드의 QR을 TV에 띄우면 학생들이 크롬북·웨일북·태블릿으로 바로 들어와요.
    로그인 없음학생 계정이 필요 없어요. 이름만 쓰고 시작해요.
    함께 하기협동·대전 게임은 방 번호로 친구들과 같이 해요.
