포트리스

대전 · 3~6학년

🎮 이 게임은 현게임의 게임 중 하나예요. 현게임 홈에 가시면 다른 게임과 QR·설명서·인기 순위를 한 곳에서 볼 수 있어요.

옛날 포트리스처럼 각도와 힘을 맞춰 쏘는 턴제 탱크 대전이에요. 내 차례마다 문제를 먼저 풀어요.

🆕 국어·수학·사회·과학·영어 3~6학년 1·2학기 전 단원으로 넓어졌어요. 학년 → 학기 → 과목을 누르면 단원이 바로 나와요.

문제를 맞히면 2번 무기(강력탄)를 쓸 수 있고, SS 게이지와 이동 연료가 늘어요. 틀리면 그 턴은 1번 무기만 쏠 수 있어요. 문제가 곧 전략이라 아이들이 진지하게 풀어요. 정답을 고르면 바로 해설이 나와서 오개념도 같이 짚어 줘요.

탱크 13종이 저마다 무기와 필살기가 달라요. 돌을 던지는 고대 투석기부터 당근 탱크, 방구 탱크, 떠다니는 UFO 탱크까지 있어서 아이들이 자기 탱크를 고르는 것부터 즐거워해요.

한눈에 보기

  • 인원: 방 하나에 2~8명, 컴퓨터·옆 친구와 대전
  • 기기: 크롬북·웨일북·태블릿
  • 문제: 3~6학년 국어·수학·사회·과학·영어 1·2학기 198단원, 우리 반 문제
  • 문제 고르기: ① 학년 → ② 학기 → ③ 과목을 차례로 누르면 그 단원이 나와요 (게임이 마지막 선택을 기억해요)
  • 주소: hyungame.duckdns.org/fortress/

수업에서 이렇게 해요

  1. 교실 컴퓨터에서 선생님 설정(9999)으로 문제 단원을 정하고, '학생이 학년·단원을 못 바꾸게 고정'을 켜요.
  2. QR을 띄우고, 모둠별로 한 명이 함께 하기로 방을 만들면 친구들이 방 번호로 들어와요.
  3. 대기실에서 각자 탱크를 고르고 '준비 완료' → 방장이 바람·제한 시간·맵을 정하고 게임 시작.
  4. 내 차례: 문제 풀기 → 해설 확인 → 각도·힘 맞춰 발사. 마지막까지 남은 탱크가 이겨요.

아이들이 좋아하는 포인트

  • 맵 12종: 초원 언덕, 붉은 협곡, 등대 섬, 눈 덮인 설원, 사막 피라미드, 하늘섬, 화산, 흔들다리, 계단 절벽, 달 기지(중력이 약해요), 쌍둥이 봉우리, 얼음 호수
  • 선물 상자와 아이템: 하늘에서 낙하산 상자가 떨어지고, 회복·방어막·바람 반대로·이동 두 배·한 번 더 쏘기·순간이동 같은 아이템을 3개까지 들고 있어요.
  • 날씨 이벤트: 가끔 회오리나 불기둥이 나타나 판이 뒤집혀요.
  • 상성: 고대 탱크는 미래 탱크에게 피해 20%를 더 줘요.

선생님이 고를 수 있는 것

  • 학년 → 학기 → 과목 → 단원(여러 개) 고르기, 학생 변경 잠금
  • 우리 반 문제 직접 입력(문제|보기1~4|정답번호|해설) 또는 엑셀, '우리 반 문제만 내기'
  • 방장 설정: 바람 없음·보통·강함, 제한 시간, 컴퓨터 실력

💡 문제는 바꿀 수 있어요. 선생님 설정 → 우리 반 문제 → [엑셀 파일 올리기]로 올리고, '우리 반 문제만 내기'를 켜면 그 문제만 나와요. 엑셀 양식 받기

이럴 때 써 보세요

  • 단원 정리 차시의 모둠 대항 복습
  • 시험 전 복습 (틀린 문제 해설이 바로 나와요)
  • 과목만 바꾸면 국어 낱말·영어 표현 복습도 탱크 대전으로
써 보니 이런 팁이 있어요
  • 혼자 해 볼 때는 첫 화면 START로 들어가 컴퓨터와 대전하면 돼요.
  • 방장 기기에서 게임이 돌아가요. 방장은 성능 좋은 기기로 정해 주세요.

실제 화면

첫 화면 문제 범위: 학년 → 학기 → 과목을 누르면 단원이 바로 나와요. 여러 단원을 골라도 돼요. (사진은 4학년 2학기 수학)

내 차례 문제: 정답을 고르면 해설과 보상이 나와요.

전투 화면: 각도계와 바람, 파워 게이지를 보고 발사해요.
